# Beyond Text: How AI Interfaces Shape Human Experience

## Anonymous Reproducibility Artifact

This repository contains the analysis code, analysis-ready data, human-validation materials, and generated statistical outputs.

The main study compares an audiovisual **Avatar** interface with a text-output **Chat** interface in a within-participant design across three research cohorts: Israel, Germany, and China.

### Main files

- **`experiment_analysis.ipynb`** - manuscript-facing statistical analysis notebook. It performs data-integrity checks, constructs the paired analytic dataset, reproduces the primary and secondary analyses, generates figures, and exports manuscript/supplementary tables.
- **`holocaust_analysis_utils.py`** - companion functions used by the notebook for deterministic preprocessing, scoring, statistical analyses, and plotting.
- **`conversations_analysis.py`** - participant-level research-cohort analysis of the three-LLM semantic annotations, including Kruskal–Wallis tests, pairwise Mann–Whitney tests, and BH-FDR correction.
- **`model-version-response-audit/`** - archived code for the historical
  post hoc paired model-version audit reported in the Appendix. The audit
  compared 50 eligible conversation turns originally answered by
  `gemini-2.0-flash-001` with regenerated responses to the same reconstructed
  prompts from `gemini-3.1-flash-lite`, followed by randomized blinded
  A/B judging with `gemini-3.5-flash`. This was a historical frozen audit
  conducted on an earlier study-data snapshot and is separate from the
  final-sample timestamp-based model-version reconstruction in the main
  notebook. Its raw historical transcripts and per-trial judge outputs are
  not included in the anonymous artifact; the archived pipeline and aggregate
  summary are provided for procedural documentation.
- **`requirements.txt`** - Python dependencies required to run the artifact.

### Data files

- **`data/study_data.csv`** - de-identified final analytic study export used by the main notebook.
- **`data/coded-messages-three-models.csv`** - semantic labels produced by three LLM judges for the message-coding analysis.
- **`human_annotations/`** - the two independent human annotation files and the coding instructions used for validation.

### Output directories

- **`analysis_output/`** - statistical tables, audit tables, paired-difference data, and manuscript figures generated by `experiment_analysis.ipynb`.
- **`conversations_analysis/`** - semantic-coding research-cohort outputs generated by `conversations_analysis.py`.

## Reproducing the main statistical analysis

Run all commands from the repository root so that the notebook can resolve the relative `data/` and output paths.

### Interactive execution

```bash
jupyter notebook experiment_analysis.ipynb
```

Then select **Restart Kernel and Run All Cells**.

### Command-line execution

A fully executed copy of the notebook can also be produced with:

```bash

  --to notebook \
  --execute experiment_analysis.ipynb \
  --output experiment_analysis_executed.ipynb \
  --ExecutePreprocessor.timeout=-1
```

## Reproducing the semantic-coding research-cohort analysis

Run:

```bash
python conversations_analysis.py
```

By default, the script reads:

```text
data/coded-messages-three-models.csv
human_annotations/human-annotation-human1.csv
human_annotations/human-annotation-human2.csv
```

and writes:

```text
conversations_analysis/llm_country_message_rates.csv
conversations_analysis/llm_country_participant_tests.csv
conversations_analysis/llm_country_pairwise_tests.csv
conversations_analysis/llm_country_summary.txt
conversations_analysis/llm_country_human_validation.csv
```

An alternative input file or output filename prefix can be supplied explicitly:

```bash
python conversations_analysis.py path/to/coded-messages.csv --prefix llm_country
```

The semantic analysis uses participant-level category proportions as the
inferential unit, rather than treating individual messages as statistically
independent observations. The inferential semantic-coding family contains
18 category tests: six tone categories, five address-form categories, and
seven question-style categories. 
Research-cohort omnibus comparisons use Kruskal–Wallis tests, with
BH-FDR correction across these 18 tests within each LLM judge. Pairwise
research-cohort comparisons use two-sided Mann–Whitney tests with BH
correction across the three country pairs within each category.

The script also reproduces the human-validation agreement statistics for the
100-message validation sample, including human–human agreement, Cohen's
kappa, agreement with each individual LLM judge, and agreement with the
two-of-three LLM majority where a majority label is available.

## Important data note

The released `study_data.csv` contains the **final de-identified analytic sample**. Participants excluded before the final statistical analysis are intentionally not included in the released analysis dataset; therefore, the 163-to-146 exclusion breakdown cannot be reconstructed from the released rows alone. The manuscript documents the participant-flow criterion and the transition from the enrolled sample to the final analytic sample.

Before packaging, direct participant names in free text were replaced with `XXXX` placeholders without deleting the surrounding messages. One `XXXX` token is retained for each original name token, preserving message word counts. This includes explicit self-introductions and participant-name echoes/direct address in agent responses. The distributed CSV files are the already de-identified release versions used for the reproducibility artifact.

## Artifact scope and omitted materials

The live participant-facing application source code, including the PHP/JavaScript implementation of condition-specific rendering and the D-ID and ElevenLabs integrations, is not included in this anonymous reproducibility artifact. The included `model-version-response-audit/prompt_builder.py` reconstruction documents the prompt-construction logic used for the historical model-version audit and should not be interpreted as the complete production application.

The character-specific knowledge-source files used for Ben Lesser and Mordechai Markel are also not included in the artifact because the authors do not have permission to redistribute these sensitive source-derived materials. The manuscript documents their construction, structure, and use in the conversational system, but the underlying knowledge files themselves cannot be released for independent inspection. Their omission does not affect reproduction of the statistical analyses reported in the manuscript, which use the de-identified study data and derived analysis files included in this artifact.

## Analysis scope

The main notebook includes:

- paired Avatar-versus-Chat tests for character connection, satisfaction/system evaluation, and knowledge accuracy;
- a first-interaction-only between-participants analysis for perceived-importance change;
- Holm correction across the four primary outcomes;
- research-cohort heterogeneity analyses using the analysis design appropriate to each primary outcome;
- adjusted sensitivity models;
- item-level knowledge robustness analysis using binomial GEE;
- the 17-outcome secondary behavioral multiplicity family;
- voice/input-modality analyses;
- exploratory Character, Presentation Order, and Gender moderation analyses;
- learning-outcome and modality-switcher follow-ups;
- the design-sensitivity benchmarks reported in the manuscript;
- recruitment-timing/model-version auditing; and
- manuscript/supplementary figure and table export.

The separate semantic-coding script exports the complete results for the coded dimensions and their multiplicity-adjusted research-cohort comparisons. Interpretation of exploratory semantic findings follows the reliability and reporting qualifications described in the manuscript.
